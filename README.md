# Inside Apparel

Inside Apparel adalah platform e-commerce yang dikembangkan untuk kebutuhan bisnis Inside Apparel.

## Tujuan

Membangun sistem e-commerce profesional yang mencakup:

- Product catalog
- Customer account
- Shopping cart
- Checkout
- Payment
- Order management
- Shipping
- Order tracking
- Customer notification
- Membership
- Voucher
- Affiliate / Brand Ambassador
- Central inventory
- Marketplace integration
- Shopee integration

## Platform

Teknologi utama:

- WordPress
- WooCommerce
- PHP
- MySQL
- JavaScript
- HTML
- CSS
- REST API
- Git
- GitHub

## Konsep Sistem

Website Inside Apparel merupakan salah satu sales channel.
